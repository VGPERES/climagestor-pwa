Sem servidor próprio e sem Google Planilhas. Cofre privado criptografado.

Importante: use um repositório privado para dados, separado do repositório público que hospeda o PWA via GitHub Pages. Token e senha nunca devem ser publicados no código. Token e senha permanecem apenas na memória durante esta sessão. Não perca a senha do cofre!

Estado da sincronização

Aguardando conexão...

Sincronização automática enquanto o aplicativo estiver aberto e conectado, aproximadamente a cada 60 segundos, além do botão manual. Alterações offline ficam neste aparelho até a próxima sincronização bem-sucedida.

Se duas pessoas editarem o mesmo registro offline, o programa apresentará um conflito para escolha, sem descartar dados automaticamente.
